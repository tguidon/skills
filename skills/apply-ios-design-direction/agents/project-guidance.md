## iOS design direction

- Use `$apply-ios-design-direction` for iPhone and iPad interface work.
- Read `PRODUCT-THEME.md` after the shared playbook when the app has one.
- Use `$capture-ios-product-theme` when an implemented app lacks reliable product-theme guidance.
- Use `$create-ios-product-theme` for a new product theme or an owner-led revision.
- A product theme can replace a playbook `SHOULD` or select a `MAY`.
- A product theme cannot override a playbook `MUST`.
